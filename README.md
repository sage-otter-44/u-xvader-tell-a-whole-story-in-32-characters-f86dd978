## Entry

> MyExTookTheDogAndTheRouter

26 characters. A breakup in one Wi-Fi name: she left, she took the dog — and, pettiest of all, the router. The dog gives you the character, the router is the twist.

## How it works

`main.ts` writes the single network name to `/output/entry.txt`. Run it with Node:
